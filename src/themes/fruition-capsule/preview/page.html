Theme Architecture & Geometry Specification

A unified layout guide establishing pixel-level container alignment between the floating glassmorphic header, index cards, single posts, and static pages.

The Fruition-capsule theme introduces a singular floating glassmorphic header pill designed to feel native, modern, and harmonious across all form factors.

1. Container Max-Width Harmony

In previous iterations, the header was restricted to a narrower width than content containers, creating a staggered boundary on high-resolution displays. Under the unified specification:

📐
The Math of Perfect Alignment:

The header pill is constrained to max-width: var(--site-max-width, 1200px), while padded content containers use max-width: calc(var(--site-max-width, 1200px) + (var(--container-padding-x, 24px) * 2)). At every viewport width, the left and right borders of all cards, banners, and header pills match down to the exact pixel.

2. Notion Headless Pipeline

Notion databases act as the CMS source of truth while Astro compiles pages into zero-runtime-cost static HTML. Key integration benefits include:

  • Zero Latency: Pages load instantaneously from edge CDN caches with no live Notion API roundtrips.
  • Asset Immutability: Notion AWS S3 image URLs are pre-fetched during SSG build and converted into permanent WebP files.
  • Relational Properties: Tags, authors, and categories are parsed into structured static JSON models.
"A static blog should feel as fast as opening a native terminal application. Clean geometry, zero bloatware."

3. Dynamic Color Presets

The theme ships with three curated color presets (Blue Sky, Mono, Candy Pop) which can be toggled without page reloads using HTML attributes: 

:root, [data-theme-preset="blue-sky"] {
  --site-max-width: 1200px;
  --container-padding-x: 24px;
  --theme-primary: #0284c7;
  --theme-glass-bg: rgba(255, 255, 255, 0.82);
}
